# webtech-wheelhouse# Wheelhouse

Wheelhouse is a system designed for a neighbourhood bicycle repair shop. It helps the shop keep track of customers, bikes, repairs, repair status, service prices, and the repair history of each individual bike.

The system is primarily used by the shop's counter staff, mechanics, and owner. Customers can also access the public service price list.
